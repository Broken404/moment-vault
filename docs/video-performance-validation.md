更新日期：2026-10-24。状态：验证入口和自制媒体已准备；取得一小时视频定位及连续调整的初步结果，但性能尚未验收。电脑操作工具因无法可靠确认 Edge 当前窗口的网址而停止本轮操作，竖屏、缓冲和三站实测未执行完，不将它们记为通过。

## 可复现入口

```powershell
$env:MOMENT_VAULT_TEST_FFMPEG = (Resolve-Path 'dist/host-library-load/media/ffmpeg.exe').Path
node tools/run-video-performance-lab.mjs
```

打开打印的回环地址，使用正式 VideoMode / VideoSession / seekFrame / FrameCache。`media=hour` 为一小时 640×360、15 fps 带时间码视频；`media=portrait` 为 40 秒 360×640、30 fps 视频；`media=portrait-low` 提供相同方向的低分辨率样本。全部由本机生成，不读取用户素材。三种站点结构仅为自制夹具，不能代替实际站点。

`network=slow` 在初始 128 KiB 后每 32 KiB 增加 350 ms 延迟；`network=timeout` 为后续内容或远距离 Range 请求增加一次 9.5 秒等待。这些是实际 HTTP 响应延迟，不覆写浏览器的 buffered/seekable 值；两条网络路径仍待浏览器验证。服务仅在 127.0.0.1:43826 提供固定文件 GET/HEAD，没有助手接口或任意路径入口，按自身路径保存请求记录。

性能观测仅在独立夹具或显式 `MOMENT_VAULT_VIDEO_PERFORMANCE_LAB=1` 测试构建启用。只在当前页面 DOM 中记录请求、帧就绪、缓存容量、媒体事件、下一次 rAF 观察及关闭后的自有控制器状态，不上传、不持久化浏览数据、不录制。正常扩展构建必须不含观测节点标识，打包检查已加入此项。
