# 悬浮球入口与首次使用

更新日期：2026-10-19。状态：产品方案细化，尚未实现或实测。

## 本轮已经明确

- 展示形式采用网页内悬浮球，并支持快捷键操作。
- 点击悬浮球后，在其旁边以打开扇子的动画展开功能菜单；目前确定三个入口：屏幕录制、设置、接收截图。
- 悬浮球在所有普通网页显示，其他网页也方便放入截图等素材；视频录制功能仅在 B站、YouTube、X 提供。此处“所有”指扩展有权限且允许注入的普通网页，不能外推为桌面、其他应用或浏览器受限制内部页面。
- 日常使用应能直接找到入口，不要求每次进入 Edge 扩展管理页。
- 产品细节按用户使用顺序逐点讨论，先明确安装后的第一步，不一次展开全部流程。
- 所有素材先进入草稿箱，经过审核后才进入资产库。原有文档中的“草稿库”与“草稿资产库”统一指草稿箱。
- 视频进入草稿箱时就保存实际视频文件，用户能够直接查看，不以时间戳、链接或缩略图替代视频文件。
- 视频录制由用户手动开始、手动结束。安装、显示悬浮球、开启选段或播放预览都不能自动开始录制；产品不进行隐蔽的后台录制。

## 当前只讨论安装后的第一个触点

建议：用户安装扩展后，在受支持且已获站点权限的网页上看到小悬浮球。首次出现时，只用一条可关闭的简短提示介绍点击入口和快捷键，不自动展开完整工作台。

悬浮球默认展示范围已确认：所有普通网页。用户在任意普通网页均可通过悬浮球使用收集入口；视频录制仍限定为 B站、YouTube、X，不能因为入口全站可见而扩大录制支持范围。

默认位置、拖动、隐藏、快捷键具体组合和各入口内部界面，按后续讨论逐项确定。本轮不同时设计完整新手引导、草稿审核或资产管理界面。

## 点击悬浮球：扇形菜单

已确认：悬浮球作为展开的中心，功能按钮从球旁边向外展开，沿扇形圆弧排列；展开和收起都有连贯动画，再次点击悬浮球时收起。当前确定三个功能入口：

| 入口 | 已确定的职责与范围 |
| --- | --- |
| 屏幕录制 | 进入视频录制相关界面，仅在 B站、YouTube、X 提供录制能力；开始和结束实际录制仍需用户明确手动操作 |
| 设置 | 配置草稿箱和资产库本地目录、语言、方向键时间步长、快捷键与悬浮球外观，并提供恢复默认操作；详见 [设置草案](settings.md) |
| 接收截图 | 展开并聚焦网页内接收区域，可直接 Ctrl + V 粘贴或拖入图片；自动保存到草稿箱并反馈结果，成功显示缩略图和“已存入草稿箱” |

非支持平台的普通网页上，三个入口仍保留原有位置。“屏幕录制”置灰、不可启动，提示“仅支持 B站、YouTube、X”；“设置”和“接收截图”继续可用。这是用户已确认的展示规则。

建议菜单根据悬浮球所在位置选择合适的展开方向，避免按钮越过视口边缘。具体扇形角度、按钮顺序、图标、尺寸和动画时长尚未确定，不在本轮擅自定稿。

## 技术实现前需要验证

网页内悬浮球需通过页面内容脚本显示，具体注入范围依赖匹配规则及站点访问权限；快捷键可使用扩展 Commands 能力。见 [Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[Commands](https://developer.chrome.com/docs/extensions/reference/api/commands) 和 [Edge 权限声明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/declare-permissions)。

这些文档支持实现方向，尚不等于首次安装、已经打开的网页、站点权限、快捷键冲突或全屏视频中的表现已经验证。浏览器内部页面与受限制页面不能直接外推为支持。
