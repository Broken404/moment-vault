# 桌宠悬浮入口与首次使用

更新日期：2026-10-20。状态：产品方案细化，正式入口与审核列表尚未实现或实测；核心采集路线的试验结果见 [技术验证记录](technical-spike-results.md)。

## 本轮已经明确

- 展示形式采用网页内 P3-C 像素圆团桌宠入口，并支持快捷键操作。
- 点击桌宠后，在其旁边展开同风格四宫格菜单；上排为屏幕录制、接收截图，下排为素材管理、设置，再次点击收起。四宫格和当前深浅色效果已通过预览，具体动作继续细化。
- 已确认按住桌宠可拖动，松开后记住位置；所有普通网页共用用户最后摆放的位置。单击仍负责展开或收起四宫格，拖动结束不误触发菜单。
- 已确认首次出现时默认放在网页右侧偏下，给底部视频控制条留出空间；已有用户摆放记录时优先沿用记录，后续打开网页不重置位置。
- 已确认右键桌宠选择“隐藏桌宠”后，隐藏所有普通网页中的桌宠；点击 Edge 工具栏的插件图标恢复显示，保留原摆放位置。
- 已确认观看全屏视频时自动隐藏桌宠，退出全屏后恢复原位置；如果用户此前手动隐藏，退出全屏后仍保持隐藏。
- 已确认默认沿用四宫格菜单预览的中号尺寸，设置提供小、中、大三档；以原预览的 48 / 64 / 80 px 对应三档，默认中号 64 px。
- 已确认桌宠默认完全不透明，不透明度可在 30%–100% 之间调节，默认 100%；只影响桌宠本体，展开菜单与各操作面板保持清晰，恢复默认设置时回到 100%。
- 已确认接收截图面板的布局与风格：桌宠附近的紧凑暖纸色面板，上方粘贴、拖入与本地选图，下方显示保存状态和本次图片；单张大预览、批量小画板。保存成功后保持打开以便连续收图，点击右上角关闭或按 Esc 收起。
- 已选择安静陪伴，平时偶尔眨眼，不主动向鼠标靠近；各功能使用不同的角色状态。已取消吃图片动画，收到图片后冒出一簇粉色像素小爱心的效果已通过预览。已确认直接把图片拖到桌宠本体就自动保存到草稿箱，无须先开菜单或面板；爱心表示收到图片，保存结果另行明确反馈。
- “素材管理”采用一个入口，在独立的浏览器标签页打开并默认进入草稿箱；页面布局与风格已通过预览，左侧切换位置、中间勾选整理、右侧查看与编辑草稿说明。页面提供本地目录打开，完整查看图片或视频时调用本地软件。
- 已确认设置与素材管理共用一个管理标签页，左侧增加“设置”入口；桌宠菜单或工具栏中的设置直接进入设置。已有管理页时复用并切换到对应功能，避免反复打开新标签页。设置采用一页四组，依次为存储位置、界面与桌宠、视频与快捷键、本地助手，底部放恢复默认设置；完整页面的视觉与操作反馈已通过预览。
- 已确认设置修改后自动保存：外观立即生效，输入项校验有效后保存，目录检查可用后切换；实际保存成功后显示已保存，快捷键通过 Edge 管理。
- 悬浮球在所有普通网页显示，其他网页也方便放入截图等素材；视频录制功能仅在 B站、YouTube、X 提供。此处“所有”指扩展有权限且允许注入的普通网页，不能外推为桌面、其他应用或浏览器受限制内部页面。
- 日常使用应能直接找到入口，不要求每次进入 Edge 扩展管理页。
- 产品细节按用户使用顺序逐点讨论，先明确安装后的第一步，不一次展开全部流程。
- 所有素材先进入草稿箱，经过审核后才进入资产库。原有文档中的“草稿库”与“草稿资产库”统一指草稿箱。
- 视频进入草稿箱时就保存实际视频文件，用户能够直接查看，不以时间戳、链接或缩略图替代视频文件。
- 视频选好起终点后，用户按快捷键从起点开始录制，到终点自动结束；中途可再次按快捷键提前结束。安装、显示悬浮球、开启选段或播放预览都不能自动开始录制；产品不进行隐蔽的后台录制。
- 视频选段与精调的布局和操作已通过预览：原进度条上拖 A/B，独立预览窗显示边界画面；精调默认收起，展开后可切换端点、缩放、局部拖动或输入时间。录制时收起完整选段界面，改用画面外的小状态条；真实三站适配和缓存性能仍待验收。
- 录制模式默认关闭，用户需要时随时调用、随时关闭；开启后菜单提供退出操作，预览窗和录制小状态条均有关闭入口。退出移除预览与 A/B 标记并恢复观看；录制中关闭先停止采集并保存已录内容，恢复观看不必等待转码和写盘，后续保存结果不重新弹出选段界面。
- 已确认独立、可自定义的“打开／关闭录制模式”快捷键，唤出只进入选段，与开始 / 提前结束录制的快捷键分开；设置显示实际绑定并提供 Edge 快捷键管理入口，未绑定时仍能用桌宠菜单和关闭按钮。
- 正常录完或用录制快捷键提前结束，实际保存成功后恢复独立预览窗，保留原 A/B 并提示“已存入草稿箱”，便于继续收集；用户主动关闭则退出，不自动恢复窗口或开始下一次录制。
- 首次使用必须先分别配置草稿箱和资产库目录；未配置完成时不能采集或审核入库，提示用户前往设置。
- 首次配置页面已通过预览：一页内分别选择草稿箱与资产库，下方显示本地助手连接与录制快捷键，其他设置先用默认值。未选齐、连接中断或目录不可用时禁用“完成配置”并说明原因；提供重新检测、安装说明或重新选择目录，完成后提示返回普通网页使用。
- 视觉已选择“灵感画板”方向；桌宠是简洁原创抽象角色的交互感，明确不要真正宠物或福瑞。现已确认 P3-C、四宫格布局、深浅色效果、安静陪伴、收图小爱心、位置与显示规则，以及默认中号、大小三档；其余界面与交互继续细化。详见 [视觉与交互设计记录](visual-and-interaction-design.md)。

## 安装后的第一个触点

建议：用户安装扩展后，在受支持且已获站点权限的网页上看到小悬浮球。首次出现时，只用一条可关闭的简短提示介绍点击入口和快捷键，不自动展开完整工作台。

目录配置是已确认的使用前置条件：尚未配置完成时，尝试收图、录制或审核入库只提示“请先设置草稿箱和资产库目录”，并提供“去设置”。两个目录配置完成且可访问后才能执行这些操作，设置入口始终可用。具体规则见 [设置界面](settings.md)。

悬浮球默认展示范围已确认：所有普通网页。用户在任意普通网页均可通过悬浮球使用收集入口；视频录制仍限定为 B站、YouTube、X，不能因为入口全站可见而扩大录制支持范围。

拖动、记住位置及首次默认位于右侧偏下均已确认；快捷键及各入口布局的其余建议见 [首版产品与技术方案](formal-plan.md)。视觉与交互尚未整体定稿，继续按设计记录一次讨论一个问题，用组合预览确认桌宠与菜单的实际表现。

## 拖动与位置记忆

鼠标按住桌宠后拖动，松开时保存最后的位置；所有普通网页共用这一份摆放偏好，后续打开网页沿用该位置。轻点仍展开或收起菜单，小幅手抖不视为拖动，真正拖动后释放不触发点击。

没有位置记录的首次使用，默认将桌宠放在网页右侧偏下，留出底部控制区域；已有记录时优先使用用户最后摆放的位置。“恢复默认位置”回到这一初始区域。具体边距随角色尺寸与视口调整，用户确认的是位置方向，不是固定像素坐标。

实现时以相对可用视口的位置记录，并在窗口尺寸变化时限制在可见区域内，避免换窗口后找不到入口。这是落实已确认位置记忆的边界处理，不表示正式拖动行为已实现或验收。

## 隐藏与恢复

右键桌宠，在简短菜单中选择“隐藏桌宠”；所有普通网页的桌宠隐藏，已经展开的桌宠菜单一并收起，隐藏期间新打开的普通网页也不显示桌宠。用户点击 Edge 工具栏的插件图标后恢复显示，沿用最后摆放位置。此操作不增加四宫格中的第五个功能入口。

隐藏入口不等于取消正在进行的录制、保存或入库任务。工具栏入口仍须能够进入设置；首次使用提示应说明如何恢复桌宠，避免隐藏后找不到入口。本次只确认交互方案，正式的跨网页隐藏、恢复和任务状态配合尚未实现或验收。

观看视频进入播放器全屏时，当前页桌宠及其菜单临时隐藏，退出全屏后回到原摆放位置。该临时隐藏不改写用户的全站显示偏好，也不影响其他普通网页；若用户原本手动隐藏，退出全屏仍保持隐藏，不自动恢复。此规则是观看时的入口表现，首版选段和录制仍先回到网页模式进行。

## 点击桌宠：四宫格菜单

此前的分散扇形圆弧排布已被紧凑四宫格替代。用户看过 P3-C 组合与主题预览后确认四宫格和明暗效果；展开和收起有连贯反馈，具体动效继续设计，再次点击入口时收起。四个功能职责继续保留：

| 入口 | 已确定的职责与范围 |
| --- | --- |
| 屏幕录制 | 进入视频选段界面，仅在 B站、YouTube、X 提供录制能力；选好区间后按快捷键开始，到终点自动结束，也可用快捷键提前结束 |
| 设置 | 在与素材管理共用的管理标签页进入设置，已有页面直接复用；配置草稿箱和资产库本地目录、语言、方向键时间步长、快捷键与悬浮球外观，并提供恢复默认操作；详见 [设置草案](settings.md) |
| 接收截图 | 展开并聚焦网页内接收区域，可直接 Ctrl + V 粘贴或拖入图片；自动保存到草稿箱并反馈结果，成功显示缩略图和“已存入草稿箱” |
| 素材管理 | 在独立浏览器标签页打开并默认进入草稿箱；提供目录打开和轻量勾选列表，可用本地软件查看，勾选多条并点击“入库”后移动完整素材文件夹 |

非支持平台的普通网页上，四个入口仍保留原有位置。“屏幕录制”置灰、不可启动，提示“仅支持 B站、YouTube、X”；“设置”“接收截图”和“素材管理”继续可用。

素材完整查看交给本地文件工具；用户通过勾选列表审核后由插件执行整夹入库移动。具体目录打开能力、批量选择和移动反馈见 [本地素材查看与审核入库](local-material-access.md)。AI 接入后置，不要求模型、密钥或 AI 分类结果才能使用草稿箱和资产库。

菜单根据悬浮球所在位置向可用空间展开，避免按钮越过视口边缘。默认尺寸、动画与入口布局见正式方案；图标和角度随具体布局实现。

## 技术实现前需要验证

网页内悬浮球需通过页面内容脚本显示，具体注入范围依赖匹配规则及站点访问权限；快捷键可使用扩展 Commands 能力。见 [Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[Commands](https://developer.chrome.com/docs/extensions/reference/api/commands) 和 [Edge 权限声明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/declare-permissions)。

这些文档支持实现方向，尚不等于首次安装、已经打开的网页、站点权限、快捷键冲突或全屏视频中的表现已经验证。浏览器内部页面与受限制页面不能直接外推为支持。
