## 用户已明确的设置

已确认入口：P3-C 桌宠展开紧凑菜单 → 点击“设置” → 在与素材管理共用的管理标签页中进入设置。管理页左侧增加“设置”入口，方便在素材管理与设置之间切换；管理标签页已经打开时直接复用并切换到设置，不反复新建标签页。工具栏中的设置入口也进入同一页面。

点击“素材管理”时进入同一管理标签页的草稿箱；点击“设置”时直接进入设置，不要求先经过草稿箱。用户已确认设置采用一页四组的布局，完整页面的风格、控件与操作反馈也已通过预览；设计通过不代表页面与标签页复用已经实现或实测。

| 设置项 | 当前要求 | 默认值或状态 |

| 资产库本地目录 | 与草稿箱分开选择，保存审核后的资产 | 由用户选择，不强制共用总目录 |

用户已经在两种目录方案中明确选择“草稿箱和资产库分别选择目录”，不采用首次强制选择一个总目录再自动建立两个子目录的方案。

## 已确认的桌宠不透明度

桌宠默认完全不透明，不透明度为 100%；用户可通过滑杆在 30%–100% 之间调节。控件明确标为“不透明度”，避免把 100% 误解为完全透明。

调节只影响 P3-C 桌宠本体，不连带降低展开菜单、图片接收面板、视频预览窗或其他操作面板的不透明度，确保文字与操作始终清晰。恢复默认设置时将桌宠不透明度恢复为 100%。该规则已获用户接受，真实显示、偏好保存与跨网页同步仍待实现和验收。

## 已确认的修改与保存方式

设置修改后自动保存，不再要求用户统一提交整页。主题、桌宠大小与不透明度等外观调整立即生效，保存成功后显示“已保存”；界面即时变化和偏好已持久保存分别处理，未写入成功时不能显示成功。

选段时间步长等输入项，在结束输入或按 Enter 后校验并保存，非法值给出就地提示并保留上次有效配置。更换目录仍先检查实际可用性，通过后才切换；取消或失败保留原目录，不迁移旧素材，任务进行中沿用禁止更换目录的规则。

快捷键在 Edge 的快捷键设置中修改，插件显示浏览器实际绑定。其他配置保存失败时保留当前编辑值并提供重试，不能将临时外观效果当作已持久保存。上述规则已确认；自动保存的实际读写、浏览器重启后的保留与跨页面同步仍需正式实现和验收。

完整设置页交互预览已获用户接受，作为正式实现的设计依据：沿用管理页外壳与既定四组结构，提供主题、语言、桌宠外观、步长输入、目录切换、助手状态与保存反馈。预览中的路径、快捷键、连接检测和保存均为示例，不读取或更改真实设置、目录和媒体；真实系统目录选择器、Windows 主题同步、配置读写与浏览器命令仍须实现和验收。

## 首次使用：先配置目录

首次配置页面已通过预览：一页内分别选择草稿箱与资产库，显示用途、路径及选择状态，下方显示本地助手连接和录制快捷键，底部提供“完成配置”；其余设置先用默认值。整体延续暖纸色、深灰、黄色强调、轻像素切角和 P3-C，不要求用户首次就逐项调整语言、外观和视频时间步长。

目录未选齐、助手连接中断或目录不可用时，“完成配置”禁用并说明具体问题。连接中断提供重新检测与安装说明，目录不可用保留当前路径并允许重新选择；配置正常完成后提示返回普通网页开始使用。正式版显示录制快捷键的实际绑定，预览中的 Ctrl＋Shift＋9 仅为示例。此处通过的是设计，真实选择与检测仍待实现和验收。

已明确：目录是使用素材功能的前置条件。草稿箱与资产库两个目录配置完成且可访问后，才能开始收图、录制和审核入库。未配置时，提示“请先设置草稿箱和资产库目录”，提供“去设置”入口；设置本身始终可用。

不先接收或录制再要求用户配置，也不静默存入其他目录。用户关闭配置提示后保留未配置状态，下次尝试使用时继续提示。目录失效或权限不足时，说明实际问题并引导修复。

## 本地目录的交互建议

- 每个目录设置项显示选择结果及访问状态，并提供“选择文件夹 / 更改”操作。使用系统目录选择器取得相应访问权限，不将一段路径文字当作已经可写。
- 选择或更改目录后检查实际可用性；不可访问、权限失效等状态应可理解，支持重新选择或授权。
- 收图或开始录制前检查目录配置，不满足前置条件时提示并进入设置；不能显示“已存入草稿箱”却只留在浏览器临时缓存。
- 有效目录可复用，不应每次接收图片或结束录制都要求重新选择。能否跨浏览器重启持续使用，以及何时需要重新授权，必须实测。
- 本地原图、视频文件与必要元数据的保存目标，以用户选择的目录为准。浏览器内部存储可用于设置、索引、句柄与必要临时数据，不能代替已经承诺的目录保存。
- 更换目录只切换当前使用的位置：后续采集写入当前草稿箱，审核入库写入当前资产库；旧素材留在原目录，需要时可切换回来。审核列表显示当前选定草稿箱中的素材。
- 草稿与正式资产仍按审核状态区分，配置了资产库目录不代表采集时可以直接进入资产库。

素材管理按用户要求直接跳转到本地文件查看，因此目录配置还应服务于“打开草稿箱 / 打开资产库”。目录读写授权与系统文件夹打开是不同能力，后者需单独验证，见 [本地素材查看](local-material-access.md)。

## 已确认的目录切换规则

草稿箱与资产库分别更换，修改其中一个不改变另一个。选择有效新目录后，将相应配置切换到新目录；旧目录及其中素材保留原地，不自动迁移、合并或删除。切回旧目录后可继续使用其中的素材。

更换草稿箱后，后续采集保存到新草稿箱，审核列表也切换为新草稿箱中的条目；旧草稿不会继续混在当前列表中。更换资产库后，后续入库写入新资产库，“打开资产库”也打开新目录，旧资产仍可通过原本地目录访问。

目录选择取消或新目录检查失败时，继续保留原配置。录制、保存或入库任务进行期间，暂不可更换目录；待当前任务结束后再切换，避免一次任务的内容被写入不同位置。

## 已确认的补充设置

用户已明确同意以下三项功能加入首版，具体视觉表现、操作方式和默认值仍需随设计预览确定：

1. **快捷键管理**：查看或修改唤出悬浮球菜单、接收截图、打开 / 关闭录制模式、录制开始 / 提前结束等操作的快捷键。模式开关使用独立命令，唤出只进入选段，不自动录制；关闭沿用模式退出与观看恢复规则。录制使用另一个快捷键切换开始与提前结束，正常到选区终点时自动结束。需处理浏览器层面的绑定方式和按键冲突。
2. **悬浮球外观**：大小、透明度以及恢复默认位置，方便避开视频和网页内容。
3. **恢复默认设置**：便于还原语言、步长或外观等配置；界面外观恢复为“跟随系统”，不删除素材，不擅自清空或更换用户选择的目录。

用户已进一步确认“打开／关闭录制模式”的独立快捷键。设置页分别显示模式开关与开始 / 提前结束录制的实际绑定，提供前往 Edge 快捷键设置的入口；未绑定时明确显示“未设置”，桌宠菜单与关闭按钮仍可使用。模式开关默认未绑定是沿用其他命令不占用额外组合的实施取值，不视为用户已选择某个默认按键组合。

## 系统深浅色同步

用户已明确需要跟随桌面系统的深色、浅色模式，便于看清。正式版默认跟随 Windows 的应用颜色模式；另提供固定浅色、固定深色，手动选择优先于系统变化，切回“跟随系统”时立即使用当前系统模式。

浅色菜单使用暖白底、深色字；深色菜单沿用深灰底、米白字。P3-C 保留深灰主体、米白眼睛与黄色角点，通过适合背景的像素描边保持轮廓清楚，避免切换主题时角色失去辨识度。描边同时用于正常网页的背景变化，不能把系统主题等同于当前网页一定为同色背景。

主题是全局外观偏好，正式版应同步到已打开的扩展界面和网页入口；切换只更新外观，不重置目录、草稿勾选、选段或正在进行的任务。当前对比图与交互预览不等于 Windows 原生同步已完成。

正式验收须在 Windows 设置中切换应用颜色模式，检查首次打开、界面保持打开、跨标签页、浏览器重启以及手动固定模式的表现；有自定义浏览器主题时仍应遵循用户选择的系统/固定规则。系统来源与本地助手连接方式在正式实现时验收，预览读取当前浏览环境的深浅色偏好，不将其直接外推为 Windows 集成已通过。

目录容量统计未进入已通过的完整设置页，本轮不纳入实施；自动清理等额外功能也不在本次范围内。

新增录制采用固定的 MP4 成片预设，首版不增加编码参数设置页；AI 模型和密钥不进入当前设置范围。

用户已明确 AI 接入后置，当前不增加模型、密钥或 AI 分类设置，也不要求配置 AI 才能完成收集与人工审核。

## 正式实现方式与验收

正式路线已选定本地助手：由 C#/.NET 助手打开系统目录选择器，持有选定目录并处理读写；扩展通过 Edge Native Messaging 使用相应操作。目录路径与实际访问检查由助手返回，不把纯路径文本当作可写权限，不把权限分散授予各个被访问网站。见 [Edge Native Messaging](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/native-messaging)。

浏览器内部存储只保存操作偏好、目录引用和临时会话，不作为最终媒体存储。两个目录不得相同或互相包含；取消选择或新目录无效时继续保留旧配置。

正式实现需验证：两个目录分别可选与可写；图片和实际 MP4 写入正确目录；中文、空格和跨盘路径；跨站共用配置；重启后的读取；取消或失败不破坏旧配置；目录不可用时反馈和重试正确。当前未更改用户的实际素材目录。
