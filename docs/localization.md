# 界面语言

更新日期：2026-10-24。状态：实现、自动检查和隔离 Edge 界面验证通过；正式扩展的语言切换与刷新保留待用户确认。依据正式方案的语言要求，提供跟随浏览器、简体中文、English；其他浏览器语言回退 English。

## 使用方式

在「设置 → 界面与桌宠 → 界面语言」选择。默认跟随浏览器的界面语言；中文语言变体使用简体中文，其余使用 English。手动指定后优先使用指定语言。设置沿用原来的本地偏好存储，成功写入后通过存储变更通知同步管理页、普通网页中的桌宠和已打开的视频选段窗。刷新后重新读取同一偏好；恢复默认时回到跟随浏览器。

翻译范围包括管理导航、设置、素材说明标签、附件种类和数量、删除确认、图片接收、保存及恢复提示、视频选段和精调控件、录制状态和快捷键说明、本地助手返回的应用错误。日期和数字使用浏览器内置 Intl；时间码仍使用原来的时分秒格式。素材名称、备注、来源、文件名、本地路径和文件内容原样保留，自动命名规则也保持一致。

扩展管理页中的名称、简介和快捷键描述通过标准 `_locales` 随浏览器界面语言显示，浏览器内部页面不受应用内手动选择控制。扩展工具栏悬停提示会随应用选择更新。系统文件夹选择器的标题由应用翻译，系统按钮和操作系统返回的原始错误细节由系统语言决定。

## 实现与维护

使用一个集中维护的中文到英文词典和 React 的订阅接口，没有新增依赖。中文作为现有保存状态和协议错误的标准文案，在显示时翻译，因此旧的未完成任务也可切换语言，不需要改写文件、迁移记录或修改助手协议。含名称或数量的整句使用位置参数；用户参数不递归翻译。未识别的外部错误保留原始细节。

`src/i18n/catalog.ts` 维护英文文案，`core.ts` 处理参数、单复数、日期及数字，`state.ts` 从偏好存储观察语言，`src/i18n.ts` 提供显示接口。新增静态界面文案须加入词典；新增持久化进度或原生应用错误也应加入，并覆盖对应参数模板。源码检查会拒绝遗漏的静态界面键和未接入翻译的中文 JSX 文本；专用开发夹具的说明文字不属于正式界面。

存储事件是语言状态的唯一更新来源，避免较早的保存回复覆盖已经到达的新语言。订阅共享一个观察器，忽略其他存储区域，并丢弃被新设置超越的初次读取。语言变化只更新文字和应用层的 `lang`，不修改原网页语言，不重建选段会话，不清空精调输入或未保存的素材说明。
