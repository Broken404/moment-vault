# 首版实施记录

开始日期：2026-10-20。实施依据：[正式方案 v1.0](formal-plan.md)。用户已明确批准定稿与开始开发，并要求做好 Git 管理。

## Git 约定

- 保留 main 与 codex/technical-spike 的既有历史；正式工作位于 codex/v1-implementation。
- 先提交批准的设计基线，再按独立职责和已执行验证提交 feat、fix、test、docs、build。提交说明只记录真实产出，不编造开发过程。
- 提交前检查差异、敏感及个人数据排除和相关检查。锁文件提交，依赖、构建产物、SDK、浏览器配置、录像与本机路径配置不提交。
- 设计定稿不打软件发布标签；完整验收、安装与说明齐备后再形成候选版本。远端同步使用普通推送，不改写已有历史。
