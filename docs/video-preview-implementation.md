# 正式视频选段与独立预览

实施日期：2026-10-22。依据 [正式方案](formal-plan.md) 和 [视频选段规则](video-range-selection.md)。本模块进入开发构建；实际录制、MP4 保存联动和视频质量最终验收仍未开放。

## 实现

- 三站各自识别视频身份和所属的完整原进度条，共用 A/B 状态、拖动、方向键、精调和预览控制器。X 从进度拖动柄的语义标签向上有限查找完整轨道，兼容中文进度标签、英文 Seek slider 和无 role=group 的实际结构；不使用散列类名，也不将 16 px 拖动柄或音量条当轨道。
- A/B 标记在原进度条上上下错开。独立窗默认宽 330 px，可移动、调整宽度，支持系统明暗主题、边界画面和一次选区试播。精调默认收起，从附近 20 秒开始，在源长度内缩放 2–120 秒；准确时间输入越界时提示，保留有效选区。
- 使用原 video 定位和解码，在独立 Canvas 显示；未新建第二个视频或复制 src。定位请求串行执行，中间目标合并，仅最新请求可发布。先核对实际帧时间，再显示边界；兼容帧回调先于 seeked 的顺序，不能只凭 currentTime 或 seeked 宣布新画面就绪。
- 每会话帧缓存最多 8 MiB、8 项，优先保留 A/B；缓存键按端点请求时间区分，保留帧的实际呈现时间。清晰度、尺寸或来源变化失效，退出释放 Canvas。试播帧直接绘制，不积累整段视频缓存。浏览器底层网络缓冲不受本模块控制，不承诺无等待或弱网性能已经通过。
- 原轨道按布局事件重新测量，相关 DOM 变化触发有限重试。同一来源的播放器重建保留选区，来源改变停止旧会话；原轨道恢复失败才提供用户主动选择的临时精调，不自动展开备用。
- 窗口使用浏览器的非模态顶层浮层，放在所选播放器的 Shadow DOM 内，页面其余区域继续可用。播放器节点移走再放回也要恢复顶层状态；播放器暂时缺席时保留关闭和重连入口。
- 关闭移除标记、浮层、事件、样式和帧缓存，取消过期结果，并在同一源视频上恢复进入前的观看位置、播放状态与设置。每个视频持有恢复租约，快速关闭再进入不会被旧回调重新播放或定位。
- 正式桌宠菜单和模式开关命令可进入/退出选段，多候选时要求点击目标视频；没有可用媒体、直播和全屏场景如实提示。录制按钮及录制命令继续说明未开放，不会开始采集或保存素材。

## 回归与证据

`npm run check` 通过 30 项前端逻辑检查、类型、格式、生产构建及实际生成 content.js 的 DOM 检查。新增逻辑检查覆盖过期结果、请求合并、取消、缓存淘汰、恢复租约、帧与定位事件顺序，以及三种轨道结构；DOM 检查覆盖正式入口、Esc 清理和录制仍禁用。模拟媒体、Popover 和 DOM 不算真实编解码或平台验收。

自制浏览器夹具使用同一套正式模块和 15 秒带时间码视频。已验证实际端点画面、原轨道拖动、缓存复用、试播到 B、进度条与同源播放器重建、关闭中断定位后的恢复、切源不写旧位置、原轨道丢失不自动降级。详细读数和真实页面结果见 [结构化记录](evidence/video-preview-2026-10-22.json)。

真实 YouTube 首轮出现“节点还连接、浮层已关闭”。最小复现为夹具按钮“移动现有播放器”：同步移走并放回同一节点，修复前 `hostConnected=true / popoverOpen=false`，修复后 `true / true`。原来的整体实例替换检查不能覆盖这个问题。现在同时观察浮层开关和页面重挂载，并在有效会话中重新打开浮层；未增加全局永久轮询。

X 的首轮完整轨道识别失败，以及初次边界画面超时，分别记录。无 group 的英文结构已形成先失败后通过的 DOM 回归；“目标帧先到、seeked 后到”已形成先失败后通过的实际队列接缝检查。真实站点结果单独记录，不凭这两项模拟回归推断全部 X 视频已通过。

更新正式扩展后，三站本次实际结果如下，数值均是页面报告的目标与已呈现帧时间，不代表定位耗时测量：

| 实际样本操作 | 目标秒数 | 呈现帧秒数 | 结果 |
| --- | --- | --- | --- |
| YouTube 影院重挂载后拖动 A | 10.653 | 10.600 | 原轨道与浮层保留，边界画面就绪 |
| B站最终构建键盘调整 A | 69.305 | 69.292 | 原轨道同步，边界画面就绪 |

## 本地复跑

```powershell
$env:MOMENT_VAULT_TEST_FFMPEG = (Get-Command ffmpeg -ErrorAction Stop).Source
node tools/run-video-preview-lab.mjs
```

打开脚本打印的本机地址。服务只允许固定文件的 GET/HEAD，支持视频 Range，不提供本地助手、文件写入或任意路径接口。媒体和截图位于忽略的 `.local-data/video-preview-lab`。`--build-only` 更新已运行服务使用的静态构建，随后必须刷新页面；夹具不进入扩展包。

播放器移动回归循环：进入选段，确认预览可见，点击“移动现有播放器”，核对连接的 Shadow DOM 中 `[popover]` 仍匹配 `:popover-open` 且 A/B 可见。该浏览器循环已分别得到失败与通过结果，不能用 jsdom 的浮层替身代替。

保存后预览恢复回归：进入选段，设 A=2、B=8，点击 B 并等画面就绪，再点击“检查保存后预览恢复”。该自制检查调用正式录制准备和释放钩子，自制驱动播放到 B 后暂停，并在释放时屏蔽新帧回调；不捕获标签页或保存媒体。旧逻辑先出现八秒超时，2026-10-23 修正后返回 B 缓存且新取帧请求为 0。故障注入仅从独立 lab 入口导入，不进入正式扩展；结果范围见 [恢复修正证据](evidence/preview-recovery-fix-2026-10-23.json)。
