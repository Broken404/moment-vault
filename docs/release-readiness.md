历史程序化高频按键波动仍为未定位诊断，不能改写为已修复，也不等同于真实鼠标拖动结果。详见 [范围澄清](evidence/v1-scope-2026-10-28.json)。下方既有结果与待办均按本节有限范围解释，不引入开放式“完整矩阵”门槛。
