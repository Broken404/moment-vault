## 推进顺序

1. **补齐素材恢复的正式扩展路径，已通过。** 附件已经收齐的「继续保存」、部分附件重新选择原文件后恢复和多语言刷新保留，均已获用户正式扩展确认；两条恢复路径的实际文件与说明也已独立核对。
2. **检查连续使用与性能。** 大图读取及正式显示、大量新素材首次加载的原生优化与规模回归、正式扩展重连后列表和预览显示均已通过。2026-10-25 按用户要求后移超长视频，补齐普通自制视频的竖屏、真实拖动、网络故障和清理检查，修正缓存被旧请求阻塞，并用正常扩展复核三站各一个普通视频。自制受控网络不等于三站逐一限速，程序化高频按键的 rAF 波动仍保留。已经通过的基础操作不逐条要求用户重做，新的预览样本也不能替代原有实录证据。
3. **自用安装包与升级验证，部分完成。** 已生成 Inno Setup 当前用户安装包，6 组隔离安装生命周期、默认位置实际安装与原生连接、保留配置和素材的只读核对及安装后 MP4 文件管线通过。真实 Edge 重连和 Windows 重启仍需分别确认，商店上架、公开发布和 AI 使用不进入本轮。见 [安装与升级](installation-and-upgrade.md)。

普通视频本轮样本与共享行为检查已完成：缓存等待从约 6.98 秒降到约 3 ms，90 项前端检查及正式构建通过；用户重新加载后，三站原轨道、边界与试播到 B 的样本通过，退出无遗留节点。不要求重复这些录制或性能场景；2026-10-26 的安装部署另需一次正式扩展重连确认。超长与其他页面组合不扩大为通过，当前状态和复跑方式见 [视频性能验证](video-performance-validation.md)。

## 首项结果：补选原文件恢复已通过

正式扩展沿用已经加载的构建，无需重新加载或录制。真实注册清单及扩展 origin 通信检查已再次通过。通过当前助手在已配置草稿目录中准备一条明确命名的自制任务「恢复验收-补选原文件」：2 个附件，视频已收齐，PNG 仅收到首个 192 KiB 分块。关闭并重新启动准备进程后仍可读出原任务，已收到的分块与目录配置保持不变；没有提交为正式草稿，没有改写既有素材。

用户在正式素材管理页通过「选择原文件继续 / Reselect originals」仅补选「待补传原图.png」，确认保存后只有一条、2 个附件。独立只读检查同一任务已经保存，且草稿列表只含一个匹配条目。

只读协议和实际文件核对通过：任务及附件 ID、顺序、名称、来源、备注和创建时间保持一致；35,697 字节 MP4 和 1,083,855 字节 PNG 均与原文件哈希一致、完整解码通过。素材内只含媒体及说明，暂存目录已清理，原文件、原修改时间与目录配置未变。核对没有重放恢复或提交，不要求重新加载或录制。
