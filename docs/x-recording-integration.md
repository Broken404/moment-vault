## 独立音量按钮修正

实际试播复核确认：播放后 X 的 `Seek slider` 消失，另外挂载一个独立 `Mute` 按钮。旧代码只给录制准备时已有的进度条祖先节点加隐藏标记，覆盖不到随后新增的按钮。正式准备函数的回归模拟这种节点切换，修正前得到 `expected hidden, actual visible` 的失败。

修正保留原生进度区域的隐藏，同时在本次录制播放器标记内使用 `Mute` / `Unmute` 按钮选择器，随后挂载的按钮也立即隐藏；释放时移除样式并恢复。两个状态的回归通过，同页其他播放器、源视频及独立音量区域不被误标记。完整 52 项前端检查通过。修正版真实采集仍待重新加载后的复核，不能由单元检查代替。
