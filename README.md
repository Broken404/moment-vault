# Moment Vault · 瞬间资产库

> 暂定名称。当前处于产品规划阶段，功能范围与技术方案仍在讨论中。

记录有意义的瞬间，经过人的筛选与 AI 的辅助，积累成可以再次使用的个人资产。

首批面向 Microsoft Edge 中的 B站、YouTube 和 X（Twitter）。资产主题开放，可以是转场、镜头、观点、文字、设计、灵感或其他值得留下的内容。

日常入口采用网页内悬浮球与快捷键，悬浮球覆盖普通网页以方便收集图片等素材，视频录制仅限 B站、YouTube 和 X。所有素材先进入草稿箱，审核后才进入资产库；视频由用户手动开始和结束录制，结束后保存实际视频文件到草稿箱，不进行隐蔽后台录制。

点击悬浮球，以扇形动画展开“屏幕录制”“设置”“接收截图”三个入口。其他网页保留录制入口并置灰，提示支持范围。

## 当前状态

产品定义与技术可行性研究阶段。仓库用于记录想法、完善方案和后续开发；尚无可安装扩展，尚未在三个平台完成实际采集验证，也未发布软件版本。

## 核心流程

发现瞬间 → 快速采集 → 草稿箱 → 人工与 AI 整理 → 审核通过后进入资产库 → 检索和复用。

采集时尽量少打断当前活动；整理时补充为什么收藏、未来怎么使用。AI 提供建议，正式入库由人决定。

## 开源目标

从规划阶段开始公开记录真实演进过程。先完善产品方案，再逐步形成能够安装、自用、验证和导出数据的完整版本。最终产品名称与开源许可证将在后续确定。

公开示例使用自制内容；用户采集的图片、视频、账户信息和模型密钥不进入代码仓库。
