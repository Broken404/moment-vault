# Moment Vault · 瞬间资产库

> 暂定名称。当前处于产品规划阶段，功能范围与技术方案仍在讨论中。

记录有意义的瞬间，经过人的筛选与 AI 的辅助，积累成可以再次使用的个人资产。

首批面向 Microsoft Edge 中的 B站、YouTube 和 X（Twitter）。资产主题开放，可以是转场、镜头、观点、文字、设计、灵感或其他值得留下的内容。

日常入口采用网页内悬浮球与快捷键，悬浮球覆盖普通网页以方便收集图片等素材，视频录制仅限 B站、YouTube 和 X。所有素材先进入草稿箱，审核后才进入资产库；视频选好起终点后按快捷键开始录制，到终点自动结束，也可再次按快捷键提前结束，随后保存实际视频文件到草稿箱，不进行隐蔽后台录制。

点击悬浮球，以扇形动画展开“屏幕录制”“设置”“接收截图”“素材管理”四个入口。素材管理可打开本地目录查看，并提供“审核入库”：从草稿箱选择认可的文件，支持多选，确认后由插件移入资产库。其他网页保留录制入口并置灰，提示支持范围。

## 当前状态

产品方案与技术验证阶段。Edge 技术试验已在 B站、YouTube、X 的普通视频样本中生成真实媒体并检查音画、终点停止与观看恢复；本地辅助路线的读写、打开目录和素材整夹入库也已实测。一条快捷键提前结束的短片存在画面停滞，尚未解决。尚未发布软件版本；更多页面类型、正式目录配置与辅助程序安装仍待实现。实验代码不代表正式产品已交付。

- [技术验证记录](docs/technical-spike-results.md)：逐项区分实际通过、准备完成与尚未验证。
- [运行技术试验](spikes/edge-local-capture/README.md)：本地测试面板、测试扩展和隔离目录。

当前阶段先明确本地收集、查看与人工审核的使用体验，AI 接入后置。

首次使用需先分别配置草稿箱和资产库本地目录；未配置完成时，采集和审核入库不可用，并提示前往设置。

## 核心流程

发现瞬间 → 快速采集 → 草稿箱 → 人工整理与审核 → 审核通过后进入资产库 → 检索和复用。

采集时尽量少打断当前活动；整理时补充为什么收藏、未来怎么使用。后续 AI 可提供建议，正式入库始终由人决定。
