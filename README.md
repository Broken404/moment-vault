# Moment Vault · 瞬间资产库

> 首版方案 v1.0 已获用户整体批准，进入正式开发。三站原进度条 A/B 为交付要求，备用仅在恢复失败后临时选择；软件尚未通过完整验收。进度见 [实施记录](docs/implementation-status.md)。

记录有意义的瞬间，经过人的筛选与 AI 的辅助，积累成可以再次使用的个人资产。

首批面向 Microsoft Edge 中的 B站、YouTube 和 X（Twitter）。资产主题开放，可以是转场、镜头、观点、文字、设计、灵感或其他值得留下的内容。

日常入口采用网页内悬浮球与快捷键，悬浮球覆盖普通网页以方便收集图片等素材，视频录制仅限 B站、YouTube 和 X。所有素材先进入草稿箱，审核后才进入资产库；视频选好起终点后按快捷键开始录制，到终点自动结束，也可再次按快捷键提前结束，随后保存实际视频文件到草稿箱，不进行隐蔽后台录制。

悬浮入口采用已确认的 P3-C 像素圆团和同风格四宫格菜单，整体界面沿用“灵感画板”的温暖纸感；用户明确拒绝动物或福瑞形象。点击入口展开“屏幕录制”“接收截图”“素材管理”“设置”，再次点击收起。素材管理在独立浏览器标签页打开，默认进入草稿箱，提供本地查看与批量审核；勾选多条并点击“入库”后，统一移动完整素材文件夹。其他网页保留录制入口并置灰，提示支持范围。

## 当前状态

正式开发阶段，实施依据为已批准的 [首版产品与技术方案](docs/formal-plan.md) 与 [定稿总审](docs/final-review.md)，设计依据见 [视觉与交互设计记录](docs/visual-and-interaction-design.md)。Edge 技术试验已在 B站、YouTube、X 的普通视频样本中生成真实媒体并检查音画、终点停止与观看恢复；本地辅助路线的读写、打开目录和素材整夹入库也已实测。一条快捷键提前结束的短片存在画面停滞，尚未解决。另已在 in-app browser 查看三站样本的原轨道结构，见 [DOM 观察](docs/evidence/native-timeline-dom-2026-10-20.json)，这不代表 Edge 原进度条集成已通过。尚未发布软件版本；实际完成与未验收项持续记录于实施记录，实验代码不代表正式产品已交付。

- [技术验证记录](docs/technical-spike-results.md)：逐项区分实际通过、准备完成与尚未验证。
- [运行技术试验](spikes/edge-local-capture/README.md)：本地测试面板、测试扩展和隔离目录。

当前阶段先明确本地收集、查看与人工审核的使用体验，AI 接入后置。

第一版聚焦采集、草稿整理与人工审核入库，提供已确认的基本删除操作。搜索、分类、检索与后续资产使用由用户另行设计。

首版采集图片与视频，不提供独立网页文字摘录；文字说明通过素材备注保留。

视频范围为三个平台中可暂停、可回看的横屏和竖屏视频，直播不在首版范围。

一次批量拖入的多张图片保存为一条素材，在同一文件夹保留各张原图和共同描述；草稿整理支持将多图、多视频或图片与视频混合归为同一条素材，各个原文件与相应说明保留。

首次使用需先分别配置草稿箱和资产库本地目录；未配置完成时，采集和审核入库不可用，并提示前往设置。

## 核心流程

发现瞬间 → 快速采集 → 草稿箱 → 人工整理与审核 → 审核通过后进入资产库。

采集时尽量少打断当前活动；整理时补充为什么收藏、未来怎么使用。后续 AI 可提供建议，正式入库始终由人决定。

## 开源目标

从规划阶段开始公开记录真实演进过程。先完成整体方案评审，再逐步形成能够安装、自用和验证的完整版本。首版沿用 Moment Vault，原创代码的 MIT 开源许可建议纳入本次整体评审，第三方组件保留各自许可。

公开示例使用自制内容；用户采集的图片、视频、账户信息和模型密钥不进入代码仓库。
